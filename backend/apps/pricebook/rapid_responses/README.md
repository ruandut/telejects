# Rapid's responses, for the contract tests

What Rapid's `connect-rapid` returns for the invented price book and provider answers set up in
`test_pricebook.py`, worked out from its views and serializers
(`api/views/connect/feasibility_views.py`, `api/serializers.py`). Field names, nesting, order,
types and grouping are Rapid's. Ids of one-site results (`"<result>"`) can't be Rapid's and are
checked for being unique integers instead.

Invented data only: no real prices, places or customers.
